# Сохранёнки · Sohri

Личный помощник для полезных находок: отправляешь материал в своего Telegram-бота,
а он оценивает, нужен ли он тебе **сейчас**, с учётом твоих целей и внимания.

Тексты, пересланные посты, ссылки, голосовые и Reels проходят один цикл:

**Сохранить → оценить по твоим приоритетам → применить сейчас / оставить на потом / убрать шум.**

Это подходит для учёбы, творчества, работы и личных интересов. Репозитории не нужны.
Работа с кодом — дополнительная возможность, выключенная по умолчанию.

## Начать через Codex

Открой папку в Codex и отправь:

> Прочитай AGENTS.md и помоги настроить Сохранёнки для меня. Используй доступную
> тебе память и контекст, уточни только актуальные цели и ограничения. Мне нужна
> приоритизация находок; работу с кодом пока не включай.

Codex предложит фокус на основе того, что уже знает, и уточнит недостающее. Имя и
биографию заново спрашивать не нужно. Если памяти нет, достаточно коротко описать
текущие приоритеты. Подтверждённый фокус сохраняется локально и передаётся боту;
бот сам не просматривает историю твоих чатов.

Готовая инструкция для передачи другому человеку: [SEND_TO_FRIEND.md](SEND_TO_FRIEND.md).

## Ручная установка

Поддерживаемый первый сценарий: **Windows, Python 3.11+, Git и установленный Codex
с действующим `codex login`**. Отдельный API-ключ не нужен; используются лимиты
твоего аккаунта. Другие ОС имеют unit-тесты в CI, но полный пользовательский
сценарий и автозапуск на них отдельно не проверены. Провайдер Claude пока не реализован.

В PowerShell из папки проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe doctor.py
.venv\Scripts\python.exe setup.py
.venv\Scripts\python.exe bot.py --check
.venv\Scripts\python.exe bot.py
```

Мастер уточнит три вещи: актуальный фокус, полезные/нежелательные темы и ограничения
внимания. Если Codex уже сохранил подтверждённый профиль, повторных вопросов не будет.
Дальше нужен **твой собственный бот** от @BotFather: токен вводится скрыто в локальном
терминале, затем нажми /start в своём боте и подтверди свой аккаунт локально.
Telegram ID определяется при этом автоматически. Не вставляй токен в чат с агентом.

Если не подтвердить аккаунт, настройка не завершается. Не запускай мастер сопряжения
одновременно с уже работающим ботом: оба используют Telegram long polling.

Для видео, голоса, PDF и DOCX установи дополнительные зависимости:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-media.txt
```

Также нужен FFmpeg в PATH. Whisper small работает на CPU; модель скачивается при
первом распознавании, если её ещё нет в кеше. Для текстов модель речи не нужна.

## Каждый день

- **Применить сейчас**: объяснение пользы и один небольшой следующий шаг.
- **В мой план**: сохранить предложенный шаг для самостоятельного выполнения.
- **На потом**: материал остаётся доступным, но не требует действий сейчас.
- **В архив**: сохранить без действий. Материалы с вердиктом `archive` сразу архивируются.

Кнопка личного плана ничего за тебя не покупает, не отправляет и не записывает в
календарь. Чтобы не копить новые обязательства, бот может ответить «это интересно,
но сейчас не нужно».

Команды: `/profile` — твои приоритеты, `/onboard` — изменить фокус, `/cancel` — отменить
уточнение, `/plan` — личные шаги, `/done 12` — отметить шаг выполненным, `/status` — очередь, `/archive` — архив,
`/item 12` — материал, `/retry 12` — повторить анализ после ошибки, `/help` — справка.

Если профиль ещё не задан, бот предложит короткое уточнение. Присланные материалы
сохраняются в очереди и ждут готового профиля. Профиль можно менять без переустановки.

## Работа на компьютере

Компьютер должен быть включён, не спать и иметь интернет. После закрытия терминала
обычный запуск остановится. На Windows можно отдельно включить скрытый автозапуск:

```powershell
# С активированной .venv:
.\install-autostart.ps1
.\stop.ps1
```

Ярлык запускает watchdog при входе пользователя в Windows; watchdog восстанавливает
бота после сбоя. Настройки сна не меняются. При длительном выключении сохранность
неполученных Telegram-обновлений не гарантируется. Это не облачный сервис 24/7.

## Дополнительно: кодовые проекты

Только по явному желанию в `config.local.json`:

```json
{
  "execution_enabled": true,
  "projects": {
    "example": {
      "path": "C:/projects/example",
      "description": "Чем полезен этот проект и какие задачи актуальны",
      "base": "main"
    }
  }
}
```

Это фрагмент настроек; сохрани остальные поля конфигурации. После изменения
перезапусти бота. Перед показом карточки бот фиксирует репозиторий, ветку и SHA.
Нажатие «Реализовать» запускает только показанную задачу от этого SHA в отдельном
Git worktree. Смена текущей ветки исходного проекта не меняет одобренную основу.
Незакоммиченные изменения не копируются. Старые карточки без зафиксированной основы
нужно открыть заново через `/item`, прежде чем одобрять.

Слияния, публикации, деплоя и покупки не выполняются автоматически. Прерванные
исполнения не повторяются сами. Codex запускается с workspace-разрешениями, а
обычный анализ — в read-only режиме с отключёнными shell и web search.

## Данные и ограничения

Секреты находятся в `.env`, настройки — в `config.local.json`, личные данные — в
`data/`. Все они исключены из исходников и релизного архива. Внутри `data/` находятся
SQLite-очередь, оригиналы, транскрипты, Markdown-архив с отдельной Git-историей,
логи и дополнительные рабочие ветки. Архив не означает удаление.

Текст и приоритеты передаются в Codex, голос распознаётся локально. Подробнее:
[SECURITY.md](SECURITY.md). Личное Telegram «Избранное» автоматически не читается:
нужно отправлять или пересылать материалы своему боту.

Лимиты: файлы Telegram до 20 МБ, видео до 15 минут, загрузка видео по ссылке до 100 МБ.
После сохранения транскрипта временное видео удаляется обычным `unlink`, без force
delete; при ошибке файл остаётся для диагностики. Закрытые Reels могут не скачаться.
Фото сохраняются без визуального анализа; PDF-сканы без текста требуют отдельного OCR.

## Разработка и выпуск

```powershell
python -m unittest discover -s tests -v
python tools/check_release.py .
python tools/build_release.py --output ../sohri-source-release
```

Последняя команда создаёт новую чистую Git-репу с одним начальным коммитом,
source-only ZIP без `.git` и файл SHA256. Старую историю, `.env` и `data/` она не
копирует. CI запускает детерминированные тесты без реальных аккаунтов и моделей.
Проверка `tests/smoke_live.py` — отдельный сознательный запуск настоящего Codex,
который расходует лимиты аккаунта и работает только с тестовым репозиторием.
